# Contribuir / Contributing

1. Abre un Issue explicando el problema o propuesta.
2. Crea un fork y una rama para el cambio.
3. Aplica `gofmt` a los archivos Go; ejecuta `go test ./...` y comprueba la compilación de Windows x64.
4. Si modificas asociaciones de Windows, descargas o importación, describe las pruebas manuales realizadas y sus resultados.
5. Envía un Pull Request con el alcance del cambio, sus limitaciones y la documentación necesaria.

No incluyas credenciales, rutas personales, enlaces privados, datos de usuarios ni beatmaps en Issues o Pull Requests. No intentes eludir controles de acceso, condiciones de los servicios o restricciones de Windows.

English contributions are welcome. Please describe the change, include tests, and avoid sharing private data.
