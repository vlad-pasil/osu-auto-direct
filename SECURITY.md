# Seguridad

La versión beta no tiene una política de soporte garantizada. Para problemas de seguridad, utiliza la opción de notificación privada de vulnerabilidades de GitHub si está habilitada en el repositorio. Si no lo está, abre un Issue solicitando un canal privado sin revelar detalles sensibles ni código de explotación.

El proyecto recibe enlaces HTTP/HTTPS de Windows y procesa archivos de servidores externos. No debe considerarse un sandbox ni un antivirus. No publiques credenciales, datos privados ni archivos maliciosos en Issues públicos.
