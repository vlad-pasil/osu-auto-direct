# Cambios

## v2.0.0-beta — primera versión pública propuesta

- Receptor nativo de enlaces HTTP/HTTPS para Windows x64.
- Reconocimiento de enlaces modernos y antiguos de osu!.
- Resolución de ID de beatmap mediante Hinai y descarga con respaldo Catboy.
- Validación estructural de archivos .osz y apertura mediante Windows.
- Reenvío de enlaces normales, configuración por usuario y desinstalación.
- Documentación bilingüe, pruebas unitarias y flujo de integración continua.

**Pendiente:** validar en Windows el registro y las asociaciones, el acceso a los mirrors, la importación real en osu! y el reenvío de enlaces a distintos navegadores. El ejecutable no está firmado.
